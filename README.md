# Task_Manager
The Task Manager Application is a console-based tool designed to help users manage their daily tasks effectively. Its primary purpose is to provide a simple yet robust interface for task creation, viewing, modification, and deletion, with all task data persistently stored in a file. Users interact with the application through a main menu, selecting options to perform desired operations. This project emphasizes professional programming practices, including object-oriented design for task representation, modular architecture for code organization, and comprehensive error handling for a reliable user experience.
